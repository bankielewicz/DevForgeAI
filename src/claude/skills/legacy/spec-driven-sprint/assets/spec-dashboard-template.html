Goal

{{GOAL_TEXT}}

  1. Orient. Read the Goal and the first non-done phase. Touch nothing yet.
  2. Create the worktree off the remote default branch — git worktree add on the remote default.
  3. Mark the phase in-progress by setting its data-status="in-progress".
  4. Develop test-first. Write the failing test before changing production code.
  5. Review against acceptance criteria — satisfy every numbered item.
  6. Commit with a conventional message; never bypass pre-commit.
  7. Open or update the PR against the base branch; link the issue.
  8. Record completion in the phase's Completion notes table.
  9. Stop and report. Do not begin the next phase — pause at the gate.
  • One worktree = one branch = one PR. Never reuse a worktree across issues.
  • Never bypass pre-commit (--no-verify is forbidden).
  • Merge only when the required check is green.
  • Never commit directly to the base branch.
