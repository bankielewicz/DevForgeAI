# Brainstorming frameworks

Choose one framework per session. Use the one the user names. Otherwise use the row whose
*use when* best fits the topic and whose *avoid when* doesn't apply. If no row fits better,
use **diverge-converge**, the default.

Read the chosen file from this directory before diverging. If the file is missing, or lacks any
of the sections *When to use / When not to use*, *Steps*, *Questions to ask*, *Mapping to the BRN*,
*Evaluation method text* and *Example*, use diverge-converge and tell the user which file was the problem.

| Framework | File | Use when | Avoid when |
|---|---|---|---|
| diverge-converge | [diverge-converge.md](diverge-converge.md) | Any open topic: a new product or feature, a pain point, or a set of options to explore and narrow down. The default | The user already has one fixed solution and only wants it critiqued or planned |
