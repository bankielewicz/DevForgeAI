# ADR-002 — Store shifts in a local SQLite file

## Context and problem statement

Which storage engine keeps shift records? This is ARCH-001's DEC-02.

## Decision drivers

- PRD-001#NFR-001: shift data stays on the user's machine

## Considered options

1. SQLite 3
2. PostgreSQL 16

## Decision outcome

**Chosen option:** SQLite 3, because it meets the driver with the least to install and run.

### Consequences

- Good: one runtime for every component.
- Bad: moving away later means a migration.

### Confirmation

The tech-stack context document lists it as a decision citing this ADR.

## Pros and cons of the options

### SQLite 3
- Good, because it meets the driver.

### PostgreSQL 16
- Bad, because it adds a dependency the driver doesn't need.
