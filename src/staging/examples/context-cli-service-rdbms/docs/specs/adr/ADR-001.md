# ADR-001 — Use Python 3.12 for every component

## Context and problem statement

Which language and runtime does shiftlog use? This is ARCH-001's DEC-01.

## Decision drivers

- PRD-001#FR-001: installable with one command on a laptop

## Considered options

1. Python 3.12
2. Go 1.23

## Decision outcome

**Chosen option:** Python 3.12, because it meets the driver with the least to install and run.

### Consequences

- Good: one runtime for every component.
- Bad: moving away later means a migration.

### Confirmation

The tech-stack context document lists it as a decision citing this ADR.

## Pros and cons of the options

### Python 3.12
- Good, because it meets the driver.

### Go 1.23
- Bad, because it adds a dependency the driver doesn't need.
