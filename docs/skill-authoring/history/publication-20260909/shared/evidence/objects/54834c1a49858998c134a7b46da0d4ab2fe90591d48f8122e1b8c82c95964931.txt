# DevForgeAI POC

DevForgeAI's intended identity is an adaptive, spec-driven software engineering framework. Follow the [adaptive design](docs/mvp/roster.md#adaptive-design) and the shared identity guidance in [AGENTS.md](AGENTS.md). Keep the current POC status explicit and describe adaptive capabilities only to the extent supported by the applicable implementation and evaluation evidence.

Read AGENTS.md and the relevant specification. Claude framework sources are in providers/claude/plugins/devforgeai/skills; use only your assigned skill and worktree. The old plugins/devforgeai source has been retired. Read docs/mvp/skill-authoring-contract.md for evaluation and packaging rules.

Use the companion installer/exporter for runtime copies. Do not load both a project-local copy and an exported plugin of the same skill during discovery evaluation. Shared contracts and Codex sources belong to their assigned owners. The companion DevForge repository owns executable gates and policy; do not edit those to accept this project's work.
