DevForgeAI intends an adaptive, spec-driven lifecycle; this candidate is a local Linux/WSL2 bootstrap experiment. Recurring interpretation is currently concentrated in operator context across assignments, shared rules and returned evidence. The proposal's “First proof and continuation” motivates comparing a reusable expert with the same bounded context packet alone. No improvement is yet observed; retaining the packet alone remains a valid later disposition.
