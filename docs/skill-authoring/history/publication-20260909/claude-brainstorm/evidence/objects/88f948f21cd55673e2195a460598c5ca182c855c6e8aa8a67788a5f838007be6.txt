`checkers/check_receipts.py`, `digest_near()`. The same-line fast path is gone. There is one
rule: the digest belonging to a locator occurrence is the nearest one with no other promised

ambiguous for that file and is rejected rather than guessed at. Reasoning by hand, the
swapped same-line pair `a.md <Hb> b.md <Ha>` now fails for both files, because each
locator's nearest digest is the other file's. That is reasoning, not a test result.
