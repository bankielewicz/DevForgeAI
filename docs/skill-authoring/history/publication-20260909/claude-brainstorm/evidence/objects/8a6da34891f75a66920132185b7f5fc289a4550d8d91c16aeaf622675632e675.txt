### CC8-PROP-001 — The prose exception permits unreadability instead of actual absence of sections

**Scope:** CHG-016 / F-016; prior CP5-CK-001 retained absence-disclosure limitation; new proposal severity high.

**Sources:** `inputs/claude/run/proposals/UNEXECUTED-PROPOSALS.json:56-62`; `inputs/claude/run/inputs/prior-run-SESSION-001-r7-20260907T1253Z/control/PLAN.json:23`; `inputs/issued-r8/REPAIR-MAP.json:288-300`; `inputs/claude/run/proposals/fixtures/chg-016-absence-disclosure/POS-disclosed-sections.md:12-17`.

**Requirement and trigger:** The selected PLAN permits omission only for a target with no stable sections and a corresponding absence disclosure; REPAIR-MAP F-016 requires an explicit absence-of-sections disclosure tied to the referenced artifact. The artifact omits upstream.sections and says its section list could not be read, without establishing that the target actually has no stable sections.

**Assessment:** The new predicate allows a disclosure that sections are unavailable OR that the artifact has none. Its positive prose case expects PASS for a section list that could not be read and calls this exactly the exception. Unreadability establishes an unknown, not actual absence. This weakens or ambiguously broadens the selected contract. The physical POS fixture is narrower and correct: it cites a target with no headings and explicitly states that fact. Thus the prose predicate/case and the authored fixture do not agree.

**Impact:** An implementer following the positive prose case could admit a no-sections claim without the observed absence required by the fixed criterion. This review does not claim the retained r7 checker already accepts a heading-present target; its existing available-sections rejection remains present.

**Required proposal revision:** Require both inspected absence of stable target sections and an explicit disclosure of that actual absence. Change the prose positive case to match POS-disclosed-sections.md. Add a negative for unreadable/unknown sections and retain rejection when a sectioned target is paired with an absence claim.

### CC8-PROP-002 — The new freeze case treats an unbound file inside the root as a frozen input

**Assessment:** The case is named unbound and demands FAIL, while its explanation switches to the whole selected set. **Impact:** As authored, the expected FAIL is unsupported and could force a broader freeze over unrelated or later-generated evidence. That would conflict with the required ability to create post-output judgments without changing the fixed criteria.

**Required proposal revision:** Separate three cases: unchanged selected inputs pass; mutation of any explicitly bound fixed input, including an unconsumed selected one, fails; mutation/creation of a genuinely unbound generated-evidence file does not itself invalidate the fixed-input freeze and is judged at its own evidence boundary.
