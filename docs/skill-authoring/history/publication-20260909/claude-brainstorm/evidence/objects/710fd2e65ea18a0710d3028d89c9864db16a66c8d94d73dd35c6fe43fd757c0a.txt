### R9-CI-004 — Structurally invalid transcript events become verified activation results (high)

Original CC7-006 (high), CHG-010.

`S/control/activation.py:88-110` counts any JSON-decodable line as an event. `_tool_uses` at 31-46 silently ignores nonobjects and malformed event shapes; only JSON decoding failures increment malformed. Therefore a transcript containing only `[]` yields one event, zero malformed events, skill_invoked false and PASS for the selected A5a negative (120-124), despite having no usable transcript event. Conversely, the function accepts a tool-use content object with neither assistant role nor assistant event type because both missing values are permitted at 36-39; that is insufficient evidence of an actual assistant turn.

The helper correctly ignores normal init metadata and recognizes the ordinary nested assistant Skill tool_use shape, but structural absence must remain unusable rather than a verified negative or unqualified positive. Require the selected event envelope and classify malformed structures separately. Also wire this parser into the actual caller as R9-CI-001 requires. No native behavior was observed here.
