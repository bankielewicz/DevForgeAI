## Material findings

### CC9-RR-001 — Section absence is still classified by entry-wide word and ID co-occurrence

Severity: **high**. The classifier is new in R9. Its false acceptance preserves the inherited absence-disclosure limitation; rejecting the mixed valid-positive disclosure is a new regression.

Locations: `inputs/claude/run/source/checkers/validate_references.py:197-206,218-231,378-395,411-441,450-454`; `inputs/issued-r9/REMEDIATION-SPECIFICATION.md:21`; `inputs/issued-r9/selected/claude/control-baseline-r7/control/PLAN.json:23`.

Requirement: Omitted upstream sections require inspected actual absence plus explicit matching absence disclosure for that artifact. An unrelated unknown must neither establish absence nor erase an otherwise valid absence disclosure. Unreadability is not absence.

Trigger: Use the unchanged, correctly hashed IDEAS-900 no-heading target and upstream from the retained physical positive. Replace only its missing_inputs entry with: "IDEAS-900 has no authoring date; IDEAS-901 has no stable sections."

Static trace: The entry supplies both IDs, a section word and an absence word. No unknown-pattern term is present. Lines 226-231 assign the same absence classification to both IDs. For IDEAS-900, check_one finds no target headings and a nonempty absence list, bypasses all omission refusals and reaches PASS, although the sole section-absence claim belongs to IDEAS-901.

Additional cases from the same predicate:

- `IDEAS-900 has no stable sections; its authoring date is unknown.` Required PASS when other reference checks are satisfied. The entry-wide _UNKNOWN search wins, absence list remains empty, and lines 411-425 return FAIL. The baseline ID-only predicate accepted this valid positive; the new parser regresses it.
- `IDEAS-900: unable to read the section list, so no sections are cited.` Required FAIL. The finite unknown regex does not match unable to read; section and no match, producing absence and eventual PASS against a readable no-heading target. Omission of citations is not disclosure of actual target-section absence.

Impact: The actual checker still accepts an undisclosed or unknown section omission, and can reject a valid exception. The new metadata target_sections_inspected and section_disclosure_kind does not repair the missing relation between artifact, section fact and disclosure.

Required revision: Bind classification to the referenced artifact and its section fact, rather than distributing one kind to every ID in an entry. Preserve valid absence plus unrelated-unknown positives; reject cross-artifact disclosures and unreadability/citation-omission negatives. Keep the selected v1 artifact contract.

Author-label assessment: BUILDER-CHANGE-RECEIPT.json:251-306 marks both CHGs APPLIED_EXECUTABLE. Executable checker code exists, but its claimed same-artifact/actual-absence behavior is incomplete. No finding closure is authorized.
