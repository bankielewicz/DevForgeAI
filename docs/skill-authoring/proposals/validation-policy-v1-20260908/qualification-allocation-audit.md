## Concrete reductions to consider without weakening assertions

1. **Batch appropriate outer grades:** the 150 paired outer outputs form 75 pairs. One fresh independent reviewer per pair, with two separate judgments, plus eight controls and one receiver would use 84 outer grading generations instead of 159: a conditional saving of 75 calls/profiles. This changes the allocation's one-arm-per-grader choice. Context limits, independence, presentation bias, complete evidence and admission timing must still hold; inadmissible pairs keep separate grades.
2. **Stop automatic nested qualification:** the 24 complete inner 17-run campaigns must be justified by actual subtask claims. Preserve representative real nested success/failure/result-return integration, real positive controls and explicit actual-run assertions. For semantic/reporting cases, select the demanded inner review/evidence rather than qualifying the scope-note fixture afresh. No reduced inner total is claimed until each selected observation and dependency is reviewed. E076 still needs the actual receiver, but the receiver's output is not automatically another complete qualification target.
3. **Reuse exact static evidence where legitimate:** 98 frozen-target reviews group into nine target-byte families (80 in one family, four in another and seven pairs), plus one future actual receiver output that has not been produced. These are candidate reuse groups, not proof that all specifications, tasks, contexts or freshness conditions match. Reuse a prior independent review only for identical scoped inputs where the source assertion does not require a newly observed invocation. Keep distinct targets and representative actual review transport. Do not claim an automatic reduction from 99 to ten reviews.
4. **Separate transport from interpretation:** 170 return generations are an architectural cost. Protected transport can persist/gather unchanged results mechanically when the parent has no intervening required judgment. Any parent that must reason, decide or produce a report still needs a counted continuation. Do not collapse an intermediate C/B/A gate using a result that does not exist yet. The needed native transport support remains unresolved; no runtime change is made here.
5. **Avoid repeated immutable setup:** materialize and hash fixed fixtures/package bytes once, then use read-only content references with fresh writable attempt/output state. Pure source/grade reviewers need isolated prompt inputs and output custody, not automatically a native installation or Git worktree; 337 of the fresh contexts are static reviewers/graders. This does not relax the explicit native attempt/worktree clauses of SV-WA or reuse contaminated writable histories. Each actual attempt still needs its own real effective-boundary check.
6. **Share compatible actual observations:** one C observation can cover several linked resources for one exact installed configuration; one actual completed task may support output quality and a compatible explicit-activation assertion when their prompt and temporal prerequisites match. One real captured negative may support several detector/adjudication assertions. Implicit activation cannot reuse a prompt that supplies the skill path; opposing conditions, changed installations or unavailable gates need distinct evidence.
7. **Do not duplicate semantic effort for mechanics:** parse errors, hash equality, counters and deterministic schema predicates use direct mechanical outcomes. Child task quality and parent evidence interpretation are distinct; a single independent review may cover both only with all raw inputs and separate conclusions. Human grading is an optional allocation choice with an actual independent owner and measured labor, not free work or an automatic substitute for required T04 AI review.

The candidate and baseline packages are not identical: builder has five changed dependency/provenance paths despite an unchanged entrypoint; validator has ten changed paths. The machine inventory lists them. Do not discard comparisons merely from matching SKILL.md bytes or different Git commit labels.

These opportunities overlap. Subtracting a removed child campaign, its grades and its returns again as unrelated savings would be false accounting. This audit retains all 28 source cases, 47 validator variants, 18 builder branches and the other resource/activation/control/receiving cases. It proposes evidence packing, not a new accepted/executable Full total.
