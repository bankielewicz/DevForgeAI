04 / Return the evidence
Export a reviewable result
  1. Save an attempt on each applicable card. Include the exact command/action, expected versus observed result, exit code, tool/platform identity and artifact references. Keep failed attempts.
  2. Capture a candidate-after manifest using the same preparation command, and compare it with candidate-before. Explain any changes. Hash screenshots, logs, raw coverage reports, fixture manifests and benchmark outputs.
  3. Stop only the daemon(s) you started using their owning fixture data environment. Preserve run directories and quarantined files. Record cleanup actions and unresolved process outcomes.
  4. Click Export results JSON and send the JSON together with the referenced evidence files or an accessible evidence directory. The export contains references, not the files themselves. Also tell me the exact checkout/candidate used.
