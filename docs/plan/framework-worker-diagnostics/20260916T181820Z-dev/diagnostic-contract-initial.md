# Closed diagnostic contract v1

Owner: compiled Rust worker probe. This contract adds observations only to the existing denial branches. Original predicate order, success projections, errors/exit codes, source and executable checks, fixed argv, all-false preflight semantics, cancellation and cleanup are preserved. An evidence-write failure retains the existing fail-closed evidence_write_failed behavior. Unknown input data never supplies diagnostic field names or values.

Every new record has kind worker_event and data {diagnostic:{schema_version:1,stage:...,...}}. It never carries authority, findings, input values, paths, identifiers, argv, raw server errors, credentials or config. Stage-specific closed fields:

* source_review: boundary post_spawn or post_preflight; predicate review_rejected. Emit only on rejection at the existing source recheck. Retain the original error.
* process_accounting: rpc initialize, config_read, other_preflight or final_check; checkpoint before_send, after_receive or final_check; predicate only_worker, unexpected_process_count or query_failed; total_processes and active_processes unsigned counts from ONE held Job Object query, both null if query fails. Preserve predicate total==1 && active==1. Record initialize/config samples and any rejection elsewhere; no extra process discovery.
* rpc: rpc initialize or config_read; predicate rpc_error, protocol_error, deadline, user_cancel, control_error, transport_error or process_guard_rejected. Emit on failure of those RPCs during preflight only; the separate accounting record explains process_guard_rejected. Preserve original result and existing config RPC error mapping.
* config_validation: section effective, origins or layers; predicate shape, fixed_keys, provider_map, endpoint_override, model_provider, login_method, web_search, sandbox_mode, approval_policy, features, apps, mcp_servers, plugins, selected_origin, source_paths, origin_source, layer_source or session_flags_count. Category identifies the FIRST failing existing validator group. Shape/type failures retain protocol_error; policy failures retain profile_unqualified as before. No second validation or value-dependent formatting. Success keeps the existing sanitized config projection.

Config labels are derived directly from the existing sequential checks, including exact session-layer keys, provider/endpoint checks, selected session origins, normalized/covered paths, every origin/layer source, bounded layer shape and exactly one session-flags layer. Multiple failing predicates report the first encountered check, not all defects. A label is an observation of a rejected predicate group, not a determination of host fault or product fault.

Bounds: existing RPC/total deadlines, Job Object ownership and journal limits apply. No retry, extra RPC, new process or thread/turn dispatch. No new input option. Existing inspectors see ordinary worker_event observations; no terminal/acceptance schema change. Testing uses local synthetic Rust peers and private source-review test seams only. Native attribution remains unproven until a separately authorized diagnostic attempt.
