# Assessment ownership after the authoring migration

The validator owns quality checks and tests for imported, specification-built, conversationally created and edited skills. Builder owns authoring contracts, custody, safe writes and readback. Builder must remain usable when validator is unavailable and returns a manual exact-byte packet.

Legacy profiles, fixtures and regressions are assessment resources. Their COMPLETE records retain their original quality and provenance semantics; do not use them to require quality-gated completion from authoring-v1. The migrated legacy build_evidence.py is a compatibility fixture interface for validator maintenance, not permission to invoke builder during ordinary assessment.

Run applicable script and deterministic cases, then use independent realistic tasks when needed for instruction behavior. Describe any required unavailable execution as NOT_RUN. Distinguish tests of the new validator from assessment performed using a preserved operational validator implementation. A validator's assessment of its own package is self-review, even if another model executes the instructions.
